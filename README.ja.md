# Gal セリフ収集ツール

[English](README.en.md) | [中文](README.md)

![Platform](https://img.shields.io/badge/platform-Windows-lightgrey)
![.NET](https://img.shields.io/badge/.NET-8.0-purple)

ギャルゲームの名セリフをワンキーで収集。スクリーンショット + OCR 自動認識 + タグ整理 + 回想スライドショー。

![メインウィンドウ](images/main.png)

## 機能

| 機能 | 説明 |
|---|---|
| **ワンキー収集** | グローバルホットキー `Ctrl+Win+Z`（カスタマイズ可）、スクショ → OCR → 自動保存；OCR は Windows 標準 / Ollama ローカル / RapidOCR から選択可 |
| **ゲーム名認識** | エンジン/日付の接尾辞を自動除去、カスタムルール対応 |
| **タグ** | セリフにタグ付け、フィルタリング |
| **グループ** | コレクション作成、1つのセリフが複数グループに所属可 |
| **回想スライド** | フルスクリーンモード、キーボード操作、ランダムジャンプ、最前面表示 |
| **エクスポート** | Markdown / JSON、全部またはグループ単位 |
| **インポート** | エクスポートした Markdown / JSON を取込 |
| **統計** | ゲーム別 / タグ別 / グループ別 / 月別・年別 |
| **自動起動** | Windows 起動時に自動起動、トレイに最小化 |
| **収集遅延** | 0〜2000ms で調整可 |

## ダウンロード

| ファイル | サイズ | 説明 |
|---|---|---|
| `Gal-quote-tool.exe` | ~28MB | 単一ファイル、.NET 8 ランタイムが必要 |
| `Gal-quote-tool_selfcontained.exe` | ~190MB | 単一ファイル、ランタイム不要 |
| `Gal-quote-tool_Setup.exe` | ~55MB | Inno Setup インストーラ（自己完結、アンインストーラ付き） |
| `publish-folder.zip` | ~77MB | 自己完結 ZIP、解凍して実行 |

> データ保存先：`%LOCALAPPDATA%\GalQuoteCollector\`

## 使い方

1. exe を実行。タスクトレイに最小化されます。
2. ギャルゲームを開き、`Ctrl+Win+Z` で収集。
3. 右上に通知が表示されます（クリックでメインウィンドウを開く）。

### キーバインド

| キー | スライド / フルスクリーン中 |
|---|---|
| `Ctrl+Win+Z` | 収集（設定で変更可） |
| `←` / `→` | 前へ / 次へ |
| `Space` | 次へ |
| `Enter` | ランダムジャンプ |
| `F11` | フルスクリーン切替 |
| `F2` | 最前面切替 |
| `Esc` | フルスクリーン終了 / 閉じる |

### グループ
- 詳細パネルでグループ名を入力 → 作成
- グレーのタグをクリック → グループに参加（緑色に）
- 緑のタグをクリック → グループから脱退
- 右クリック → グループ削除
- ツールバーでグループ選択 → フィルタリング

### ゲーム名ルール
設定画面でカスタムルールを追加。例：`Summer Pockets → Summer Pockets REFLECTION BLUE` と設定すると、タイトルに "Summer Pockets" を含むウィンドウはすべてそのゲーム名に自動マッピングされます。

## 開発

### 環境
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- Windows 10+

### ビルド
```bash
cd GalQuoteCollector
dotnet build
dotnet run
```

### パブリッシュ
```bash
# フレームワーク依存（小）
dotnet publish -r win-x64 -c Release --self-contained false -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o ./publish

# 自己完結（ポータブル）
dotnet publish -r win-x64 -c Release --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o ./publish
```

## 技術スタック
- **.NET 8 + WPF** — デスクトップフレームワーク
- **Windows.Media.Ocr** — ネイティブ OCR（Ollama / RapidOCR に切替可）
- **SQLite** — ローカルデータベース
- **CommunityToolkit.Mvvm** — MVVM アーキテクチャ
- **Hardcodet.NotifyIcon.Wpf** — システムトレイ
- **System.Drawing.Common** — スクリーンショット & 画像処理

## 更新履歴

### v1.2.6（2026-09-13）
- **修正** 回想の超解像が**誤ったウィンドウ**に効いていました。以前は回想ウィンドウを開いた時点で発動し、小さい方のウィンドウを拡大していました。**F11 で全画面にした時**に発動し、**全画面のそのウィンドウ**を超解像するよう変更（全画面を抜ける／閉じると解除）
- **修正** Magpie のログで実際に効いたか確認するように：ホットキーはトグルなので、**他のウィンドウを拡大中に押すとそのセッションが止まるだけ**です。その場合は自動でもう一度送信し、超解像を全画面の回想へ移します（ステータスにも表示）
- **修正** 全画面を抜ける時にやみくもにホットキーを送らないように（直前に終わったセッションを再開して小さいウィンドウを拡大してしまっていました）。先に Magpie のログを確認します
- **訂正** v1.2.5 で「Magpie が管理者として動作しているとホットキーが無効」と書きましたが誤りでした。実測では管理者権限でも注入は有効です
- **追加** 診断スイッチ `--open-slideshow`（超解像を強制した状態で回想を開き、全画面→解除まで自動で実行）
### v1.2.5（2026-09-13）
- **修正** 起動時の TranslucentTB 修復が効かなかった問題：ログオン約1秒後に再起動していたため、シェルがまだ準備できていませんでした。タスクトレイ領域の出現を待ち、さらに20秒待ってから再起動し、タスクバーのピクセルで確認、変化がなければ30秒後にもう一度だけ再試行します
- **変更** 撮影方法の既定を**現在のモニター**に変更：Magpie の超解像ではゲームのタイトルバーが消えないため、ウィンドウ単位の撮影ではタイトルバーが入ってしまいます
  - 既存の設定は一度だけ自動移行（`auto`／空 → 現在のモニター）。あとから自由に戻せます
  - 「Magpie 実行時はネイティブ解像度を優先」は既定でオフ（オンにするとタイトルバーが入ります）
- **追加** 回想モードの **Magpie 超解像**：**F11 で全画面**にすると Magpie がその全画面ウィンドウを拡大し、全画面を抜けると解除します
  - ホットキーは Magpie の設定から**自動取得**（手入力も可）。Magpie が起動していなければ起動を試みます
  - 設定に「Magpie 設定を読み込む」「テスト」ボタン：テストはホットキーを送信し、Magpie のログで実際に反応したか確認します
  - Magpie がゲームを拡大中の場合は、超解像をこの全画面ウィンドウへ移します（ゲーム側のセッションは停止します）
- **追加** 回想ウィンドウの画像を高品質な拡大アルゴリズムに変更
